# Mobile-first interface checklist

Use this skill for layouts, forms, dashboards, and responsive interaction design.

- Start at narrow phone widths, then progressively enhance tablet and desktop layouts. Avoid horizontal scrolling and keep primary actions reachable.
- Use semantic HTML, clear heading order, visible focus states, keyboard-accessible controls, and labels/instructions that do not rely on placeholder text alone.
- Maintain readable contrast and comfortable text sizes. Do not communicate status or scores through color alone.
- Give touch targets comfortable size and spacing. Keep dense conversation content scannable and distinguish prospect messages from learner messages with more than color.
- Design loading, empty, validation, offline/error, and completion states—not only the ideal path.
- Respect reduced-motion preferences. Keep animation nonessential, brief, and supportive of comprehension.
- For private evaluations and histories, avoid exposing one learner's data in shared UI or client-visible state.
